**Rationale:** all four excluded documents (14, 19, 24, 27) are index pages. They mostly link to other pages and hold no content useful to the assistant (stated by the project owner 2026-09-24, OD-3). The reason is also recorded per ID in `corpus/manifest.json`.

**Source of truth:** files in `corpus/sources/` are read-only originals.

**Manifest:** `corpus/manifest.json` lists every accepted document (ID, title, source URL, size, SHA-256, heading counts). The per-section inventory is in `data/processed/documents/section-inventory.jsonl`. Both are generated by `scripts/utilities/build_corpus_inventory.py`; rebuild them instead of editing by hand. Location decided by the owner 2026-09-24 (OD-2).

The current dataset consists of 24 accepted Markdown documents (the original brief said 25; #25 never existed), but the ingestion architecture is designed to support additional document formats (PDF, HTML, others via parser adapters).
