## How to review
In the **Decision** cell of each row write one of:
- `approve`: the question, answer and source are right;
- `fix: <what to change>`: the row is kept and corrected (for example, wording, a missing point, a wrong heading);
- `reject`: the row is dropped and replaced, or the count is reduced (say which).

Use **Note** for anything else. Decisions survive a refresh of the tables
(`.venv/Scripts/python.exe scripts/evaluation/build_review_sheet_v2.py`).

What every row was checked for already (`scripts/evaluation/validate_questions_v2.py`, OK): every evidence quote is an
exact substring of its section in the converted text (corpus 2) or the normalized corpus (corpus 1). The check is
whitespace-insensitive and quotes come from prose only. Every required point has a quote; every unanswerable row has
absence terms with 0 hits in all accepted documents of both corpora; typing matches the text (`no_diacritics` = a
Vietnamese question typed with no tone or shape marks). The validator cannot check that the answer is right for
the question, that the question is natural, or that no other passage answers it better. That is what this review is for.

Things worth a look:
- Heading paths: most corpus-2 PDFs have no headings, so the heading path is `""` (whole document, ADR-0008).
  C2-07 has a single heading near the top, so almost all of it sits under `*1.1.* Hoàn cảnh quốc tế…`.
- C2-08 quotes are stored in decomposed Unicode (NFD) as in the converted text; they look identical here.
- Q2-EVAL-027 / 028 test the near-duplicate pair C2-04 / C2-22 (028: a fact found only in C2-04).
- C2-21 heading paths look odd (`number`, `number Please answer # 7.`): the PDF extraction turned lines starting with
  `#` into Markdown headings. They are the real inventory paths, so citations will carry them.
- C2-18 quotes keep the PDF's ﬁ / ﬂ ligatures exactly as extracted; source typos (`in3Dmode`, `solu- tion`) are kept.
- Q2-EVAL-020 and C2-26 rows: the documents keep key content (flowchart, formulas) in images; the answers use only
  the text and `must_not_claim` forbids the image-only details.
