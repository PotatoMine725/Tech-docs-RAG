## Explain it back
- **Why two insufficient layers?** The gate is cheap: it skips the LLM when nothing is close, which saves quota and
  prevents answers built on weak context. It is tuned conservatively (lowest answerable dev score − 0.05), so it never
  refuses an answerable dev question, and the LLM's own `insufficient` flag handles "close but not covered". The
  alternative was a single layer. LLM-only costs a call per question and trusts the model to refuse; gate-only needs a
  threshold that separates cases perfectly, and with scores this close (0.674 vs 0.736) that would be fragile.
- **Why dedup by passage, not by content hash?** Duplicates matter because identical passages have identical vectors
  and would take several of the 5 slots with the same information. `content_hash` hashes raw Markdown, so doc 17's
  repeated sections, which differ only in link URLs, looked distinct (2 duplicates found vs 26 real ones). Hashing the
  link-stripped body the LLM actually reads catches all of them. `duplicate_chunk_ids` keeps the dropped IDs so
  evaluation can still credit an expected span that only a dropped copy overlapped.
- **Why JSON mode with a schema and a hard error on bad output?** Structured output makes `insufficient`,
  `cited_passages` and `missing_information` machine-checkable. A parse failure raises `GenerationError` with the raw
  text instead of silently becoming "insufficient", because that would hide model failures inside the refusal rate the
  evaluation measures.
- **Why numbered passages and markers instead of free-form citations?** Markers `[n]` map to exactly one retrieved chunk,
  so each citation carries a real heading path and excerpt from our data, never a location the model invented. Markers
  outside 1..k are removed and counted (`dropped_markers`) as a hallucination signal.
- **Why is the threshold tuned on the dev set only?** Tuning on the eval questions would leak the test into the system
  and inflate results. The dev set is tiny (6), so the value is a documented estimate, and the evaluation reports how
  often the gate fires.
